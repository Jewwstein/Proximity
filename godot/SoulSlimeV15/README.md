# Soul Slime Godot 4.7.2 migration test

This build replaces the custom Android mesh renderer with Godot 4.7.2's real 3D engine/import pipeline. It preserves the v10 four-room vertical slice and loads the original Meshy FBX assets directly for the Molten Razorbeast and Armored Voidweaver, with their 2K PBR maps.
