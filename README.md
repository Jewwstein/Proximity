# Plain Sight v0.3.0

Native CameraX camera with offline multi-angle personal-item learning. Replaces the WebView prototype that froze the screen while loading a 156MB detection model.

Open camera, say or type Find my keys. Use + to teach eight views of your specific key fob (rotate it slowly). Search then scans camera snapshots for matching features, highlights possible regions while keeping the camera preview live.

The image embedding model is bundled in the APK; no download on first learning. Basic general image label classification is supported for untaught names but does NOT locate arbitrary novel objects. Precise personal-item recognition is experimental, particularly for small shiny keys. Results should be checked visually.
